# Examples for 01-terminology

## Abstract examples

A manuscript calls a standard pullback square a “synchronization square” once. Giving a local definition does not earn that name a place: write the pullback square and describe its maps.

A lemma introduces `a_j`, then a later calculation uses `a_{ij}` for restrictions to pieces `U_i`. Even if the intended meaning can be guessed, define the indexed quantity before the calculation. In contrast, a standard summation index need not receive an artificial glossary entry.

An isomorphism of vector spaces does not specify an algebra isomorphism. Name the product or cite the separately established compatibility at the point where the stronger identification is asserted.

## Extracted notation is not authoritative

A PDF text extractor prints a decoration on one line and the arrow on the next. Reading the arrow alone may turn an isomorphism into an arbitrary map. Do not add a new hypothesis or report an absent comparison theorem on that basis. Check the original rendered formula or the exact-version mathematical source, including its surrounding assumptions. The same rule applies to a dropped “op”, a dual, a degree shift or a variance-changing subscript. Source criticism requires a faithful reading of the source.

## Underlying data versus the structure used

Calling a Banach space “the space of vectors” does not specify whether subsequent open sets refer to the norm topology or the weak topology. Name the topology used before discussing those opens. Likewise, checking the standard word “compactness” does not verify an added technical label such as “adaptive compactness”; compare the full term and its definition. A private glossary cannot repair missing public definitions. Likewise, the rational span of 1 inside the real numbers is not thereby a real vector space: identify the actual scalar field and closure before using scalar extension. An ambient structure does not automatically restrict to every generated subobject.

## Finding the construction does not verify its name

Suppose the manuscript calls a familiar map a “defect-annihilating map,” while the cited definition calls exactly that map a quotient map. Copy the short source name “quotient map” into the source-wording field. Recording the manuscript phrase there, even beside the correct reference, has not established that phrase as terminology. Nor does a row combining “kernel”, “quotient” and “defect-annihilating map” under a single “verified” verdict settle the third name. Use “quotient map,” or describe what the map kills in an ordinary sentence if that fact is useful. Compare each candidate name and its definition separately, including unchanged occurrences. If another passage still says “apply defect-annihilation,” rewriting the longer map label has not removed the unsupported operation name. Check that surviving name separately and use the established operation or an accurate plain clause. This is not a requirement that every descriptive sentence occur verbatim in the literature. If a later hypothesis instead says “for every adaptable pair,” a private note that this means the already defined pairs in P does not bind that new class phrase; refer to P or state the actual condition.

## Declaring a domain can accidentally strengthen a claim

Integration is defined on every integrable real function, but the identity integral(f)=integral(|f|) used for nonnegative f does not hold on that whole domain. Adding “let f be any integrable function” to explain the notation would change the claim. Retain nonnegativity at the identity. Similarly, a tensor symbol with an unambiguous conventional meaning needs no glossary, but its two scalar fields cannot be silently identified. An earlier definition of a product between categories does not by itself define the same printed symbol between two objects. If the latter denotes a module action, identify that action publicly; the types of the operands and a private audit note cannot supply the missing convention. If a datum is a triple (V,T,v) and an argument proves v=0, say that its distinguished vector vanishes; “the datum is trivial” also makes an unsupported claim about V and T.

## Standard properties versus a new label

“Compact connected Lie group” combines independently established properties of a Lie group; it needs no exact-phrase citation and introduces no new kind. “Compression-stable group,” by contrast, cannot be certified from separate references for compression and groups. State the actual stability property, or meet the strict necessary-new-name exception if a new recurring concept genuinely needs a name. Decide from the mathematical use and source definitions, not hyphens, phrase frequency or a private “descriptive” label.

## Comparing the same concept

A primary work defining chain complexes is not a second treatment of derived tensor product merely because derived tensor product acts on complexes. Find a treatment of that operation itself and compare its definition and hypotheses. An earlier treatment with stronger boundedness assumptions can still provide a useful comparison; it cannot justify the later unbounded theorem. Record the difference instead of counting adjacent background as the second comparison.

## Compare the actual convention, including claimed matches

If a reference defines Df=f′ while the manuscript uses Df=a f′, the reference does not supply the factor a. Record the source formula and state the additional convention separately, even if both operators are familiar. If an introductory formula uses a locally named function space E, a definition of E three sections later is not a preceding or attached declaration. The final symbol traversal must check the order, not merely find a definition somewhere.
